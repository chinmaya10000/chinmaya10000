## 🚀 Key Projects

### 🔹 [GitOps-based CI/CD on EKS](https://github.com/chinmaya10000/eks-gitops-terraform)
- Built a complete GitOps pipeline using **Jenkins**, **GitHub Actions**, **ArgoCD**, and **Helm**
- Managed infrastructure using **Terraform**; deployed microservices to **Amazon EKS**
- Integrated **SonarQube**, **Trivy**, and **Bitnami SealedSecrets** for secure and quality deployments
- Followed best practices with **IRSA**, **OIDC**, private subnets, and image scanning

### 🔹 [AMI Pipeline with Jenkins + Packer + Terraform](https://github.com/chinmaya10000/ami-pipeline)
- Automated **AMI creation using Packer** triggered via Jenkins
- **Terraform** used to update Launch Templates, Auto Scaling Groups, and **ALB with SSL via ACM**
- Enabled **blue/green deployments** and hardened security with IAM roles and S3 state locking

### 🔹 [3-Tier Web App Deployment on AWS](https://github.com/chinmaya10000/3tier-app-aws)
- Deployed **Node.js frontend/backend** and **RDS** in private subnets with public ALB
- Used **Terraform modules**, **ASGs**, **SSL/TLS via ACM**, and **Bastion host** for access
- Enabled **cross-region RDS replication** and cost-optimized infrastructure
